Slash Commands

Manage reading, queues, volume, and voices directly within Discord.

Command Description Permission
/reader join Connects the bot to your current voice channel and starts reading text posted in its chat. Server Member
/reader leave Disconnects from the voice channel and ends the session. Operator / Member
/reader pause Pauses speech narration without leaving the voice channel. Operator / Controller
/reader resume Resumes speech narration for newly posted messages. Operator / Controller
/reader skip Immediately skips the currently speaking message. Server Member
/reader clear Purges all pending messages waiting in the queue. Operator / Controller
/reader voice [name] Switches the narrator voice (e.g. coral, ballad, shimmer). Operator / Controller
/reader volume [0-100] Adjusts playback volume percentage for the server. Operator / Controller
/reader status Displays session uptime, queue depth, active voice, and monthly usage. Server Member
/reader help Displays the in-app quick reference guide and supported commands. Server Member

Frequently Asked Questions

Everything you need to know about channel privacy and behavior.

Does it read messages from #general or other text channels?

Never. The bot enforces strict voice channel isolation. It only reads messages typed inside the built-in text chat of the voice channel it is currently connected to.

What happens when everyone leaves the voice channel?

The bot is audience-aware. It pauses speech narration immediately if no humans are in the voice channel, and cleanly disconnects after a 60-second grace period.

Can users inject prompt attacks like "ignore previous instructions"?

No. VC Reader verifies the transcript of every generation against narration safety rules to guarantee text is read strictly verbatim without answering questions or conversing.

Why isn't the bot reading my message?

Ensure that: (1) You ran /reader join while connected to the VC, (2) you are typing in that exact VC's chat panel, and (3) you are not muted/blocked by the bot.
