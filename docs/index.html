Slash Commands

Control your reading session directly in Discord.

Command Description Permission
/reader join Connects the bot to your current voice channel and starts reading text posted in its chat. Server Member
/reader leave Disconnects from the voice channel and ends the session. Operator / Controller
/reader pause Pauses speech narration without leaving the voice channel. Operator / Controller
/reader resume Resumes speech narration for newly posted messages. Operator / Controller
/reader skip Immediately cuts off the currently speaking message. Server Member
/reader clear Purges all pending messages currently waiting in queue. Operator / Controller
/reader voice [voice] Switches the narrator voice (marin or cedar). Operator / Controller
/reader volume [0-100] Adjusts the bot's audio output loudness percentage. Operator / Controller
/reader status Displays session uptime, queue depth, participants, and monthly budget usage. Server Member
/reader help Displays the in-app quick reference and disclosure rules. Server Member
